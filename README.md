# AI Scam Shield
AI Scam Shield is a proposed security assistant designed to help users identify potential digital scams.

Key Features

- Suspicious message analysis
- URL risk checking
- Risk levels with explanations
- Safety guidance for users
- Hindi and English support

Technology Stack

- HTML
- CSS
- JavaScript
- Python
- Flask

Project Status

Currently in the planning and practice stage. Features will be implemented and tested during development.
